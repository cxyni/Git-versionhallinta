## Osiossa käyttämäni Git-komennot

| Komento | Kuvaus |
| --------| ------ |
| git reset| poistaa kaikki tiedostot stage-alueelta|
| git restore| peruuta muutokset yhteen tiedostoon|
| git restore .| peruuta kaikki muutokset|
| git clean -fd| poista uudet tiedostot|
| git revert HEAD| peruuta viimeisin talletus|
| git log| talletusten historia|
